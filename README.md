
# Instagram Engagement Dashboard (Power BI)

An interactive Power BI dashboard analyzing user engagement on a simulated Instagram dataset, built on top of a MySQL relational database.

## Features
- User growth trend over time
- Top 10 most engaged users (by likes)
- Top 10 posts by likes
- Top 10 most commented posts
- Follower growth over time
- Interactive date-range slicer

## Tools Used
- Power BI Desktop
- MySQL (data source)
- DAX measures for aggregations
